# 本机生产启动与巡检清单

本清单用于正式制作前的快速确认。首次安装或重装请先完成[安装指南](installation.md)，日常制作方法见[使用指南](user_guide.md)。

## 1. 启动前

- [ ] 当前分支或版本标签明确，`git status --short` 没有不认识的改动；
- [ ] `ffmpeg -version`、`uv --version`、`nvidia-smi` 均可运行；
- [ ] `.venv`、`environments/qwen3tts/.venv`、`environments/cosyvoice/.venv` 均存在；
- [ ] 模型、作品目录和目标磁盘有足够空间；
- [ ] 重要项目已用 `scripts/backup_project.ps1` 做冷备份；
- [ ] 9000、8001～8004 没有残留的旧平台或 worker。

平台与 worker 均停止时执行：

```powershell
.\.venv\Scripts\python.exe .\scripts\platform_doctor.py --startup
```

验收标准：汇总为 `0 failed`。默认一键启动要求八份模型 manifest 全部满足。

## 2. 启动平台

仅本机使用：

```powershell
.\start_platform.bat
```

- [ ] 启动器显示平台已运行；
- [ ] 浏览器可以打开 `http://127.0.0.1:9000/web/`；
- [ ] `http://127.0.0.1:9000/api/v1/ready` 返回 `{"status":"ok"}`；
- [ ] 页面顶部 API 状态正常；LLM/Whisper 未配置或未加载时允许显示待机状态。

平台目前没有账户、TLS 或权限系统。除非是防火墙保护下的受信任局域网，不要使用 `--lan`，严禁直接暴露公网。

## 3. 启动 TTS 后端

在“平台配置”中选择本次生产所需后端并点击启动/加载模型：

- [ ] 页面顶部显示正确后端和“已加载”；
- [ ] 当前只运行一个 8001～8004 worker；
- [ ] 切换后端后旧 worker 已释放；
- [ ] 用无敏感内容的短句完成一次样音合成；
- [ ] 样音可播放，无削波、异常静音、截断或明显重复。

IndexTTS2 当前辅助供应链包含标记为 `CC-BY-NC-4.0` 的 MaskGCT。未替换或取得单独许可前，不要把该链路用于收益性生产。

## 4. 打开正式项目

- [ ] 项目名称、角色、章节和发音词典正确；
- [ ] 参考声音、内置音色或 VoiceDesign 描述均有来源/授权记录；
- [ ] A/B 两槽和历史 Take 符合预期，没有误清理；
- [ ] 自动分段或 JSON 导入前已确认：它们会替换当前分段列表；
- [ ] 批量合成期间不手动切换 TTS worker；
- [ ] 任务列表可以显示运行中/完成/失败任务，停止后可恢复未完成工作。

## 5. Master 前

- [ ] 所有用于正式 Master 的分段都选择了最终 Take；
- [ ] 关键分段已标记“已通过”，问题备注已关闭；
- [ ] 非破坏编辑预览与编辑导出一致，原始 Take 仍可恢复；
- [ ] BGM / Ambience / SFX 的来源、许可证、商业使用范围和备注完整；
- [ ] Dialogue 优先级、BGM ducking、淡入淡出和峰值听感合理；
- [ ] 完整质检通过后再生成不可变 Master。

## 6. 发布前

- [ ] 完整试听最终音频，检查开头、结尾、段落衔接和静音；
- [ ] 响度、真峰值、削波和文件格式满足目标平台要求；
- [ ] SRT/VTT 时间轴与最终 Master 对齐；
- [ ] 标题、作者、简介、章节、封面和版权声明正确；
- [ ] 发布包包含音频、字幕、元数据、授权清单和校验和；
- [ ] 发布包中没有 API Key、私人参考声音、工程临时文件或日志。

## 7. 收工

1. 等待任务队列进入终态；
2. 停止 TTS worker，确认显存释放；
3. 关闭启动器，让平台执行优雅退出；
4. 对重要工程执行冷备份并验证清单；
5. 不把 `dubbing_projects/`、`models/`、声音或生成媒体提交到 Git。
