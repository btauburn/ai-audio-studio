# Automatic Voice Lab and one source-bound listening test

## Why

Studio already owns immutable Takes and original Qwen character identities, but
performer discovery and version-bound preference review require manual work.
Imported subset indexes also cannot establish the literal first chapter of a work.

## What Changes

- Add bounded official performer/performance discovery, evidence, eligibility and
  explainable ranking driven by actual voice-version feedback.
- Extend canonical Studio project/voice-library state for original and eligible
  reference identities, immediate reversible feedback, explicit assignment and
  bounded discovery through the existing durable job owner.
- Link a shared accessible Voice Lab player from Studio and the private delivery
  page. Keep Brian-only access, MK disabled, and proxy mutations to Studio.
- Gate a single natural 285–315-second Chapter 1 excerpt on actual local source
  metadata, complete contiguous text, four resolved dialogue characters and narrator.
- Integrate existing Qwen VoiceDesign/Base conditioning and production Take/QA
  rendering; no automatic demonstration batches or extra comparison editions.

## Impact

Additive project defaults and existing voice-library metadata, new Studio routes,
existing private player routes, and an eligible-reference worker capability.
Existing production casts, global worker configuration, selected Takes and audio
are preserved. No upstream application code is copied, published or deployed.

The supplied local EPUB and snapshots contain 256–260, not Chapter 1. The feature
must expose this blocker and perform no requested test synthesis until the source
and all passage constraints pass.
