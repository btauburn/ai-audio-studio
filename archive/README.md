# Archive

This directory preserves upstream and pre-production documents for provenance
and migration research. Its contents are **not current installation or usage
instructions**.

Use these maintained documents instead:

- installation: [`docs/installation.md`](../docs/installation.md)
- production workflow: [`docs/user_guide.md`](../docs/user_guide.md)
- architecture: [`docs/architecture.md`](../docs/architecture.md)
- operations: [`docs/operations.md`](../docs/operations.md)
- license boundaries: [`LICENSES/README.md`](../LICENSES/README.md)

The upstream IndexTTS readmes and historical product-plan documents remain
here so later maintainers can audit origins and decisions without presenting
obsolete commands to new users. Machine-specific recovery reports and private
operational inventories are intentionally not part of the public source tree.
