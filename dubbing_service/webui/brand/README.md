# Brand assets

The AI Audio Studio mark depicts four source tracks converging into one master
waveform. It represents Dialogue, BGM, Ambience, and SFX joining the release
Master.

- `logo-mark.svg`: application mark and browser favicon
- `logo-mark-256.png`: launcher/window icon source
- `wordmark.svg`: README and long-form brand lockup
- `social-preview.svg`: editable GitHub social-card source
- `social-preview.png`: 1280 × 640 GitHub social preview
