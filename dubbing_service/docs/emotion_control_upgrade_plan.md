# IndexTTS2 情感控制升级方案（轻量版）

> 版本：v2.1 (Lite) | 更新日期：2024-12

---

## 方案定位

**精品有声书模式**：专注于挖掘 LLM 的文本描述能力和 IndexTTS2 的长文本表现力。

---

## 已实施的修改

### 1. 上下文注入（Context Injection）

**目的**：为自回归模型提供前文铺垫，提升情感稳定性

**修改文件**：
- `app/providers/tts.py`
- `app/routers/synthesis.py`
- `app/routers/settings.py`

**实现逻辑**：
```
emotion_text = f"前情提要：{previous_text[-N:]}。当前状态：{current_emotion_description}"
```

**配置项**（v2.1 新增）：
- `context_injection_length`：上下文注入长度，默认50字符，设为0可禁用

---

### 2. 提示词重构（Prompt Engineering）

**目的**：让 LLM 生成"生理情境描述"而非抽象形容词，并强制长段合并

**修改文件**：
- `app/routers/segments.py`

**核心规则**：

1. **长段合并策略**：同一角色连续发言务必合并为一条 JSON
2. **生理情境描述法**：
   - 第一步：角色状态/情境模拟（"像刚被吵醒的熟睡者..."）
   - 第二步：情绪与技术参数（语速、声音质感等）
3. **普通段落兜底**（v2.1 新增）：平静叙述不必过度戏剧化

**特殊情境示例**：
| 描述 | 效果 |
|------|------|
| "像刚被吵醒的熟睡者，语速较慢，声音含糊不清" | 模型自动生成哈欠声 |
| "像刚进行完百米冲刺，大口喘着粗气" | 模型生成明显呼吸声 |
| "像怕惊动什么东西，极度压低嗓音" | 模型生成极具压迫感的气声 |
| "像强忍着眼泪，声音哽咽" | 模型生成哭腔 |

**普通段落示例**：
- "平静自然地叙述，语速适中，不带特殊情绪"
- "娓娓道来，像在讲述一个平淡的往事，从容不迫"

---

## 配置说明

在"TTS 参数配置"页面可调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `context_injection_length` | 50 | 上下文注入长度（字符），0=禁用 |

---

## 验证方法

1. **测试上下文注入**：合成连续分段，观察情感过渡是否自然
2. **测试提示词效果**：LLM 分段后检查 `emotion_description` 是否为生理情境描述
3. **测试普通段落**：确认平静叙述不会被过度戏剧化
